# SQLite 索引执行计划

2026-10-17：在空业务数据的本地库执行 EXPLAIN QUERY PLAN，仅验证查询路径，不代表大数据量性能。

## 我的预约

```sql
SELECT * FROM reservation WHERE user_id=1 ORDER BY created_at DESC
```

```text
(4, 0, 62, 'SEARCH reservation USING INDEX reservation_user_created (user_id=?)')
```

SELECT id FROM reservation WHERE status='CONFIRMED' AND pickup_deadline<='2026-10-17'

(2, 0, 47, 'SEARCH reservation USING COVERING INDEX reservation_expiry (status=? AND pickup_deadline<?)')

## 时段占用

```sql
SELECT * FROM slot_occupancy WHERE device_id=1 AND slot_start='2026-10-17'
```

```text
(3, 0, 39, 'SEARCH slot_occupancy USING INDEX sqlite_autoindex_slot_occupancy_2 (device_id=? AND slot_start=?)')
```
