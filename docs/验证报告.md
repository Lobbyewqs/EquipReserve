# 本地 MVP 验证报告

## 2026-10-19：MySQL 安装与数据迁移

环境：Windows、Python 3.14.7、MySQL Community Server 8.4.9 / InnoDB、PyMySQL 1.2.3。MySQL 官方 ZIP 内 `mysqld.exe` 的 Oracle America 数字签名 Valid。仅监听 127.0.0.1:3306。

` .venv\Scripts\python.exe -m unittest -v test_platform test_mysql `：**36 项通过，53.591 秒**（SQLite 16 项、真实 MySQL 20 项）。最终显式建表排序规则配置另补跑幂等键比较测试，1 项通过。Python 编译、JavaScript 语法与 git diff 空白检查通过。

- MySQL 的 100 个并发用户竞争同槽：只有 1 条预约和 1 条占用，99 个 SLOT_OCCUPIED；本轮耗时 2.906 秒，只用于正确性验证。
- 同键 20 次并发请求重放相同 ID，改变内容复用同键返回冲突；不同尾部空格的幂等键保持不同。
- 创建占用后注入异常，预约、占用、成功幂等记录与成功审计全部回滚。
- 取消/领取、领取/过期、逾期阻塞、旧归还重放、停用及设备添加/删除权限保持正确。
- 手动持有设备 1 行锁时，设备 2 的预约仍可成功；数据库生成列唯一索引直接阻止同设备第二笔 BORROWED。
- HTTP 测试覆盖登录、CSRF、预约、重放、越权、添加设备和删除归档，均使用独立随机 MySQL 测试库。
- SQLite → MySQL 迁移测试保留密码哈希、历史、占用和当前借用指针；非空目标库拒绝再次导入。

本机正式数据迁移结果：3 个账号、6 台设备、1 条预约、0 条占用、4 条幂等记录、6 条审计、1 条会话。导入前创建 SQLite 一致性快照，导入事务提交前逐表逐字段校验；原 SQLite 文件仍保留。保留已有密码，不做密码重置。

SQL 备份实测恢复到随机隔离 MySQL 库，7 张表全部字段与源数据一致，测试库随后删除。安全关闭、重新启动 MySQL 后数据保持不变。更新后的平台实际连接 MySQL 8.4.9，首页 HTTP 200，未登录设备 API HTTP 401。已生成 `MySQL索引执行计划.md`，数据量很小，不作性能结论。

限制：未验证生产负载、死锁自动重试、掉电或强制终止恢复、HTTPS 和登录后的浏览器全流程。本节记录本地验收结果，GitHub 同步状态以仓库为准。以下为此前 SQLite 版本验证记录，其中“未验证 MySQL”描述仅对应当时版本。

## 实测结果

`python -m unittest -v test_platform`：**12 项通过，11.579 秒**。

| 场景 | 结果 |
| --- | --- |
| 100 个用户竞争同设备同槽，100 个工作线程 | 1 个成功、99 个 SLOT_OCCUPIED；预约与占用各 1 条 |
| 同用户同键 20 个并发请求 | 同一预约 ID；改变内容复用键返回冲突 |
| 创建占用后注入异常 | 预约、占用、成功幂等记录、成功审计均回滚；同键可重试成功 |
| 取消旧预约后重新预约，再次取消旧预约 | 新占用保留 |
| 时段开始时取消与领取竞争 | 取消被拒绝，领取成功，实物指针一致 |
| 截止时刻领取与过期竞争 | 领取失败，状态 EXPIRED，实物未借出 |
| 截止后重建 Store 并补扫 | 1 次过期；重复扫描 0 次变化 |
| 前笔逾期、后笔领取、归还旧笔后再领取 | 先阻止，归还后可领；旧归还重试不清空新借用 |
| 设备停用 | 禁止新预约和领取；允许归还；占用保留 |
| 权限与所有权 | 他人预约取消 404；普通用户借还 403 |
| 时间边界 | 28 个时段；开始前不可领、截止前一秒可领；14 日范围外拒绝 |
| 真实 HTTP | 首页 200、未登录 401、CSRF 403、预约 201、重放 ID 一致、管理员接口 403、登出后 401 |

100 请求竞争这一轮耗时 5.441 秒。此数字包含本机 SQLite 写串行化和审计写入，属于正确性测试记录，不是吞吐量基准，也不代表 MySQL 性能。

Python 编译与 JavaScript 语法检查通过。本地首页返回 200，浏览器中实际打开并检查了登录页。登录后的设备、预约、管理界面尚未逐项进行浏览器点击验证；没有声称前端全流程已通过。

## 环境问题与修复

最初测试使用系统临时目录，被受管 Windows 权限阻止打开 SQLite 文件；改用项目内隔离的 data/tests 临时目录。第一次 HTTP 测试被沙箱回环网络策略阻止，随后在允许本机连接的执行环境下完整重跑，12 项全部通过。没有关闭系统安全功能。

## 未验证

- 强制终止进程/掉电恢复。当前重启补扫测试重建数据库连接与 Store，未模拟操作系统崩溃。
- 登录后浏览器点击流程、移动端截图、不同浏览器兼容性。
- HTTPS、生产部署与另一台机器的复现。
